## 3. 画面1 ひょう（あいうえお表）

**役目**: 46字を一度に見せ、押した字のページへ行く。はなまるを取った字が分かる。

**並び**（草案から変更）

- 10列×5段。**右端の列が あ行、左端が わ行**。各列の上から あ段・い段・う段・え段・お段。
- 欠けているマス: や行の い段・え段、わ行の い段・え段。**点線の枠に薄い「・」**、押せない。
- わ行は草案のまま **わ（あ段）・を（う段）・ん（お段）** に置く（や行と同じ見え方）。

**見た目**

- 上端の1行: 左に題「なぞって あいうえお」（32px）、右に「**ふたりで**」ボタン（ふたりの絵＋字・高さ 56px・画面6 へ）、「◎ はなまる 12 / 46」（24px・数は朱色）、いちばん右の隅に「**？**」ボタン（56px・画面5 へ）。
- 「？」は、おとなに知らせることがあるとき（声が無い・記録できない）だけ、右上に朱色の **！** 印が付く。
- マス: 目安 88×96px 以上（使える高さ 690px に5段が収まる大きさ）。角丸・行の淡色の地・行の濃色の字（48px 以上・丸ゴシック）。
- はなまる済みのマス: 右上に朱色の **◎**（形で分かる）。
- **この画面は上下に動かない**（1画面に収める・R10）。

**操作**

- 字のマスを押す → 画面2（その字の もじページ・「え と ことば」タブ）へ。URL は `#ka` のように字のキーを付ける。**音は出さない**。

## 7. 画面4 なぞる

**役目**: 指で字をなぞり、なぞれたら はなまる。**上の子向け**（下の子は描いて遊ぶだけでよい）。

**配置**

- 右の列の左側に **なぞり枠**: 正方形。1辺は「使える高さ」と「横 1024px から左の列・ボタン列・余白を引いた残り」の**小さい方**（目安 500px・R23）。地は行の濃色。練習帳の**十字の点線と内枠**、真ん中に**白い字**（丸ゴシック・最も太い字形）。
- 右の列の右側（幅 150px 前後）に上から:
  1. 「**できた！**」— **はなまるの絵**＋字（朱色・高さ 80px 前後・R18）
  2. 判定のことば（24px）
  3. 「**けす**」— **けしごむの絵**＋字（できた！ より小さく目立たない色・高さ 56px 以上・R18）
  - できた！ と けす の間は **32px 以上**あける（押し間違いで線が消えないように・R19）。

**操作**

- **なぞるタブを押したとき**、最初の案内「しろい せんの うえを ゆびで なぞってね」を字で出し、**声でも言う**（押したときに鳴るので CLAUDE.md §4 の範囲・R20）。
- 枠の中を指（または Apple Pencil）でなぞると濃い線が引ける（線の太さは枠の 9% 前後＝600 のうち 56。画面の上では 48px ほどで、指の腹とほぼ同じ幅・§7 下の注）。枠の中ではページが動かない・拡大しない。
- **最初に触れた1本の指だけで描く**。ほかの指（手のひら・2人目の指）は、その指が離れるまで無視する（R21）。
- 「けす」→ 線と はなまるの絵を消し、判定のことばを最初の案内に戻す。
- 「できた！」→ 判定して、**ことばを出し、同じことばを声でも言う**（押したときだけ鳴る）:

| 条件（草案のまま・下の注で確かめる） | ことば・声 | ほかに |
|---|---|---|
| 何も描いていない | まだ なにも かいてないよ | — |
| なぞれた割合 ≥ 55% かつ はみ出しが少ない（線の 45% 以上が字の近く） | はなまる！ よく できました | 枠に**朱色のはなまるの絵**を重ねる（0.3秒以内に出る）・その字を記録する |
| なぞれた割合 ≥ 30% | もうすこし！ しろい せんを ぜんぶ なぞってね | — |
| それ以外 | しろい せんの うえを なぞってみよう | — |

- 「ちがう」「だめ」など否定のことばは使わない。
- 書き順は出さない・判定しない（草案のまま・§9）。
- 別のタブへ移って戻ると、線は消えて最初からになる。

**判定のしくみ**（草案のまま）: 見えないキャンバスに**枠と同じフォント・同じ位置**で字を描いて「字の本体」と「許容範囲（本体を太らせたもの）」の2枚の型を作り、描いた線と比べる。枠の字と型は同じ描き方から作るので、フォントが読めずに別の丸ゴシックになってもずれない。描き始める前に、その字のフォントを明示的に読み込み終えてから枠と型を作る。

**注: 線の太さは測って決めた**（R24・2026-09-14・`tests/trace-measure.html`）。字の中心線を1回なぞったときの なぞれた割合（46字のうち いちばん低い字）: 太さ 30（草案）→ 39%（ふ）・48 → 65%・52 → 70%・**56 → 76%（そ）**。全字 70% 以上に余裕をもって届く **56** にした（草案の 30 では、正確になぞっても はなまるにならない字があった）。はなまるの閾値（55%・45%）は草案のまま。枠いっぱいに横線を引いて塗りつぶしても、線の 18〜42% しか字の近くに入らないので「もうすこし」止まりで、はなまるにはならない。字形やフォントを変えたら測り直す。

## 8. 画面の外で決めること（全画面共通）

**読み上げ**

- 端末の読み上げ（`speechSynthesis`・日本語・ゆっくりめ）。**押したときだけ**話す。新しく押したら前の読み上げは止める。
- **声の一覧で読み上げを止めない**: 毎回 `lang='ja-JP'` を付けて呼ぶ（声の一覧は最初に空で返ることがあるので、それで「声が無い」と決めない・R2）。声の一覧がそろったあとで日本語の声が無いと分かったときだけ、画面5 に一言出し、「？」に ！ 印を付ける。
- **1字の読み**: データの各字に「よみ」を持たせ、1字だけ読むとき（大きな字を押したとき）はそれを使う。既定はその字そのもの。実機で読み違えた字（例:「は」を「わ」と読む）だけ、よみ を差し替える（カタカナで書く・「は、はなの は」のように単語を添える など・R5）。

**記録**

- はなまるを取った字だけを端末の `localStorage` に覚える（キー `hira-stars`、中身は `{ "ka": 1, … }`）。子ども別には分けない（§10-1 で決定）。
- iOS では、**ホーム画面のアイコンから開いたときと Safari から開いたときで記録が別々**になり、Safari から開く使い方では、しばらく開かないと記録が消されることがある。⇒ **開くのはホーム画面のアイコンだけ**と決め、画面5 に書く（R6）。
- 保存できないときも画面は動かす。画面5 に一言出し、「？」に ！ 印を付ける。

**読み込みの失敗を無言にしない**

- HTML には最初から「ひらいています…」を書いておき、JS が動き出したら消す。
- JS が読めない・途中で止まったときは、画面に**こまった顔の絵**と「うまく ひらけませんでした。おうちの ひとに いってね」を出す（絵を見れば大人を呼べるように・R8）。

**配信とオフライン**（`docs/hosting.md` をもとに決めたこと）

- `.github/workflows/pages.yml`（hosting.md のものを、2026-09-14 時点の最新の版＝checkout v7・configure-pages v6・upload-pages-artifact v5・deploy-pages v5 に上げた）で、`main` への push のたびに `site/` を GitHub Pages に上げる。`site/.nojekyll` を空で置く。
- 各 HTML に `<meta name="robots" content="noindex">`。
- `site/manifest.webmanifest`（`display: standalone`・`start_url: ./`・`scope: ./`）と、ホーム画面のアイコン（180px の PNG）を置く。ホーム画面のアイコンは**いつも表から開く**。
- `site/sw.js`（サービスワーカー）: キャッシュ名に版（`kids-v1` など）を付け、`site/` の全ファイルを先読みし、キャッシュを先に使う。**更新するたびに版を上げる**（上げ忘れると iPad が古いまま）。
- 更新が iPad に届くのは、アプリを閉じて開き直したとき（1回目で取りに行き、2回目から新しい版）。画面5 に書く。

**フォント**

- Zen Maru Gothic（SIL Open Font License）を**画面で使う字だけにサブセット化**した woff2 を `site/fonts/` に置き、ライセンス文も同じ場所に置く（§10-4）。
- 作り方は `.venv/bin/python tools/fonts.py`（元の TTF は `fonts-src/`、道具は `.venv/`。どちらも git に入れない）。残す字は、ひらがな全部・`site/` の中の かな と記号・英数字・「行」。漢字は画面5（おとな向け・iPad 内蔵のフォント）にしか出ないので入れない。**子ども向けの画面に字を足したら作り直す**。
- 読めなかったときは iPad 内蔵のヒラギノ丸ゴシックで表示する（表示も判定もそのまま動く）。

**動く環境**（iPad Air 2 ＝ iPadOS 15 の Safari）

- Safari 15.0 で動く書き方だけを使う。**使わないもの**: CSS の入れ子（nesting）・コンテナクエリ・`color-mix()`・`:has()`・`dvh`／`svh` の単位・`<dialog>`・JS のトップレベル `await`。
- 古い端末（メモリ 2GB）なので、なぞりの判定は「できた！」を押したときに1回だけ計算する（描いている最中は計算しない・草案のまま）。

**画面の規約**（CLAUDE.md §4 をこの画面に当てたもの）

- インライン `style=` を書かない。**行の色は `data-row="1"`〜`"10"` の属性で CSS 側に10通り書く**（草案は JS で `style` に書いていた）。
- 子ども向けの文字は 20px 以上・押す的は 56px 以上を目安（最低 44px）。
- **押せる物は、押したら 0.3秒以内に見た目で返す**（少し縮む）。声が出ないときも押せたと分かるように（R3）。
- 行の濃色は、①淡色の地 ②白い字 ③なぞった線 の**どれとも比 3:1 以上**（R22）。なぞった線を草案どおりの暗い色（`#25313A` 前後）にするなら、行の濃色の明るさ（相対輝度）は **0.19〜0.26 の間**が目安。
- 動きは 0.3秒以内・`prefers-reduced-motion` のときは止める。
- **拡大させない**: ピンチ（2本指で広げる）・ダブルタップ・長押しの拡大鏡とメニューを、どれも出さない（子どもが拡大されたまま戻れなくならないように・R1）。
- **縦向きのときは**、画面の代わりに「**よこに してね**」の**絵**（横に回す iPad の絵）と字だけを出す（R7）。
- 外部リンク・広告・入力欄は置かない。

## 14. ふたりで あそぶ 画面の共通の決まり（画面6・画面7）

2026-09-15 決定（ユーザー: ①ものさがし と ④いっしょに タワー の両方を採用し、①から作る。触れるモックで置き方と積み木の形を確かめた）。

**目的**: 知育と、兄弟仲良く。4歳の兄が遊びたくても2歳の弟が追いつけない、を解く。1台の iPad で2人が一緒に遊ぶ。

**決まり**

1. **弟の操作は、どこを押しても間違いにしない**。押したら必ず声か動きで返し、否定のことばは出さない。
2. **兄には「教える役・決める役」を渡す**（読んで伝える・ヒントを出す・どこに積むか決める）。
3. **勝ち負け・時間制限・個人の得点を置かない**。数えるのは「ふたりで」の1つの数だけ。
4. **画面を2つの側に分け、同時に触っても こわれない**。指ごとに受け付けるので、2人が同時に押しても両方効く（この画面では「最初の1本の指だけ」の決まり＝R21 は使わない）。

**置き方**

- iPad を机に平らに置き、向かい合って座る。
- 既定は **短い辺の両側**: 画面を左右に分け、各自の側を自分のほうへ回して描く（左の側は右へ90度、右の側は左へ90度）。左が兄・右が弟。
- 画面5 で **長い辺の両側** に切り替えられる: 画面を上下に分け、上（兄）の側を逆さまに描く。記録は端末の `localStorage`（キー `futari-place`、値 `short`／`long`）。
- 座る側を入れ替えたいときは、iPad を180度回す（画面の決まりは変えない）。

**そのほか**

- 呼び方: 画面には「おにいちゃん」「おとうと」とひらがなで出す（名前は出さない）。各自の側は色でも分ける（兄＝さ行の青、弟＝は行の朱）。
- 入口: 画面1 の見出しの「ふたりで」ボタン。画面7 ができたら、ボタンの先を「どっちで あそぶ？」を選ぶ画面にする。
- 「もどる」は**兄の側の隅にだけ**置く（弟が間違って押さないように）。いつも画面1 に戻る。
- 記録はしない。数えるのは その回だけで、画面を出たら 0 に戻る。
- 声は押したときだけ。動きは 0.3秒以内（§8 と同じ）。

## 15. 画面6 ものさがし

**役目**: 兄が字を読んで伝え、弟が絵を探す。見つけたら「ふたりとも はなまる」。

**配置**（短い辺・既定。各自の側の中の並び）

- **兄の側**: 上に「おにいちゃん ・ よんで あげてね」（20px）。その下に、**大きな字のカード**（その回の ことば・96px・♪ 印・押すと読む）。横に上から「**ヒント**」（電球の絵＋字）・「**◎ ふたりで N こ**」・「**もどる**」。

- **弟の側**: 上に「おとうと ・ えを おしてね」（20px）。その下に **絵 12枚**（4列×3段・1枚 120px 以上）。

**ことば**

- `KIDS.SAGASU`（`data.js`）から出す。2歳が知っている身近な物で、兄が読みやすい **2〜3字の語** だけ。絵は あいうえお と同じもの（`KIDS.ICONS`）。

- 1回ごとに28語から12語を選んで並べ、その中の1つが こたえ。前の回と同じ こたえは続けない。

**操作**

- 兄が **字** を押す → その語を読む。
- 弟が **絵** を押す → その絵の名前を読む。外れても何も否定しない。

- 2人が同時に押しても両方効く（§14 の決まり4）。

**知育**: 兄＝ひらがなを読む・人に伝える／弟＝物の名前と音、絵と言葉の対応。
