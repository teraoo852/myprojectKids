| 項目 | 草案 | 初版 | 理由 |

| 行の色 | 淡色の地に濃色の字で比 1.8〜3.2 | **比 3:1 以上**になるよう濃い方を暗くする（色相は保つ） | 9行が 3:1 未満（黄の た行は 1.82）。なぞり枠の白い字も同じ理由で見えにくい |
| 色だけの意味 | 単語中の強調・選ばれたタブが色だけ | **下線・印も添える** | CLAUDE.md §4「色だけで意味を伝えない」 |
| 判定の伝え方 | 文字で出す・声は成功時だけ | **3通りとも声**で言う・成功時は**はなまるの絵**を重ねる | 下の子も上の子も文を読めない |
| 同じ字が2回ある語 | 最初の1字だけ強調（みみ・もも） | **全部強調** | 両方とも同じ字だと分かるように |

| 入力 | touch＋mouse の別処理 | Pointer Events にまとめる（指・Apple Pencil・マウス） | 処理を1本にする |
| 色の設定 | ライト／ダーク両対応 | **ライトのみ** | 行の色を1通りに固定し、実機確認も1通りにする |

## 3. 画面1 ひょう（あいうえお表）

**役目**: 46字を一度に見せ、押した字のページへ行く。はなまるを取った字が分かる。

**並び**（草案から変更）

- 10列×5段。**右端の列が あ行、左端が わ行**。各列の上から あ段・い段・う段・え段・お段。
- 欠けているマス: や行の い段・え段、わ行の い段・え段。**点線の枠に薄い「・」**、押せない。
- わ行は草案のまま **わ（あ段）・を（う段）・ん（お段）** に置く（や行と同じ見え方）。

**見た目**

- 上端の1行: 左に題「なぞって あいうえお」（32px）、右に「◎ はなまる 12 / 46」（24px・数は朱色）。
- マス: 目安 88×96px 以上（1024×768 横の Safari で5段が縦に収まる大きさ）。角丸・行の淡色の地・行の濃色の字（48px 以上・丸ゴシック）。
- はなまる済みのマス: 右上に朱色の **◎**（形で分かる）。
- 押したとき: 0.1秒だけ少し縮む（`prefers-reduced-motion` のときは動かない）。**音は出さない**。

**操作**

- 字のマスを押す → 画面2（その字の もじページ・「え と ことば」タブ）へ。URL は `#ka` のように字のキーを付ける。

**表の下**（スクロールした先・おとな向け・16px）

- 使い方の説明（3タブの使い分け、はなまるは「この iPad に」覚えること）。
- 次のときだけ一言出す: 日本語の読み上げ音声が無い／はなまるを保存できない（プライベートブラウズ等）。

## 4. もじページの共通枠（画面2〜4）

**配置**（横向き・草案から変更。草案は縦に積む）

- **左の列**（幅 240px 前後）: 上から
  1. 「‹ もどる」ボタン（高さ 56px 以上）
  2. **大きな字**（160px・行の濃色・淡色の角丸の地）——押すと**その字を読み上げる**
  3. 行の名前「か行」（20px）
  4. タブ3つを**縦に**並べる: 「え と ことば」「ことば」「なぞる」（各 高さ 64px 以上・24px）。選ばれたタブは行の濃色で塗り、**左に ▶ を付ける**（色だけにしない）。
- **右の列**: 選ばれたタブの中身（画面2〜4）。

**操作**

- 「もどる」・Safari の戻る・画面端からのスワイプ → 画面1。表は戻るたびに描き直し、はなまるの ◎ と数を最新にする。
- URL の `#ka` を直接開いたら、その字のページから始める。知らないキーなら画面1。
- タブを切り替えても URL は変えない。開いたときは必ず「え と ことば」から。

## 5. 画面2 え と ことば

**役目**: 絵と単語と声で字を覚える。**下の子が主に使う画面**。

- 単語カードを2枚、横に並べる。1枚の中身: 絵（正方形・1辺 最大 300px・白地）、単語（40px）、「♪」印。
- 単語の中の**その字は全部**、行の濃色＋**太い下線**で強調する（例: みみ → 2字とも）。
- **カードのどこを押しても単語を読み上げる**。
- 絵のキーが見つからないときは、絵の場所に大きな「？」を出す。
- **特例**
  - **を**: カードは出さず、説明「「を」は ことばの あいだで つかう もじだよ」と例文「**ほんを よむ**」を出す。例文は押すと読み上げる。
  - **ん**: 説明「「ん」で はじまる ことばは ないよ。「ん」で **おわる** ことばを みてみよう」を上に出し、その下に ぱん・りぼん のカード（草案から変更: 草案はこのタブに説明が無かった）。

## 6. 画面3 ことば

**役目**: 絵に頼らず単語を読む。**上の子向け**。

- 単語2つを縦に並べる（各 64px・枠付き）。絵は出さない。
- 強調のしかた・押すと読み上げ・を／ん の特例は画面2と同じ。

## 7. 画面4 なぞる

**役目**: 指で字をなぞり、なぞれたら はなまる。**上の子向け**（下の子は描いて遊ぶだけでよい）。

**配置**

- 右の列の左側に **なぞり枠**: 正方形、1辺 500px 前後（左の列 240px＋枠＋右のボタン列 150px が横 1024px に収まる大きさ）。地は行の濃色。練習帳の**十字の点線と内枠**、真ん中に**白い字**（丸ゴシック・最も太い字形）。
- 右の列の右側に縦に: 「**できた！**」（朱色・大）、「**けす**」、判定のことば（24px）。ボタンは高さ 64px 以上。

**操作**

- 枠の中を指（または Apple Pencil）でなぞると濃い線が引ける（線の太さは枠の 5% 前後）。枠の中ではページが動かない・拡大しない。
- 「けす」→ 線と はなまるの絵を消し、判定のことばを最初の案内「しろい せんの うえを ゆびで なぞってね」に戻す。
- 「できた！」→ 判定して、**ことばを出し、同じことばを声でも言う**（押したときだけ鳴る）:

| 条件（草案のまま） | ことば・声 | ほかに |
|---|---|---|
| 何も描いていない | まだ なにも かいてないよ | — |
| なぞれた割合 ≥ 55% かつ はみ出しが少ない（線の 45% 以上が字の近く） | はなまる！ よく できました | 枠に**朱色のはなまるの絵**を重ねる（0.3秒以内に出る）・その字を記録する |
| なぞれた割合 ≥ 30% | もうすこし！ しろい せんを ぜんぶ なぞってね | — |
| それ以外 | しろい せんの うえを なぞってみよう | — |

- 「ちがう」「だめ」など否定のことばは使わない。
- 書き順は出さない・判定しない（草案のまま・§9）。
- 別のタブへ移って戻ると、線は消えて最初からになる。

**判定のしくみ**（草案のまま）: 見えないキャンバスに**枠と同じフォント・同じ位置**で字を描いて「字の本体」と「許容範囲（本体を太らせたもの）」の2枚の型を作り、描いた線と比べる。枠の字と型は同じ描き方から作るので、フォントが読めずに別の丸ゴシックになってもずれない。描き始める前に、その字のフォントを明示的に読み込み終えてから枠と型を作る。

## 8. 画面の外で決めること（全画面共通）

**読み上げ**

- 端末の読み上げ（`speechSynthesis`・日本語・ゆっくりめ）。**押したときだけ**話す。新しく押したら前の読み上げは止める。
- 日本語の音声が無い端末では無音で動かし、画面1の下に一言出す（§3）。

**記録**

- はなまるを取った字だけを端末の `localStorage` に覚える（キー `hira-stars`、中身は `{ "ka": 1, … }`）。子ども別には分けない（§10-1 で決定）。
- 保存できないときも画面は動かす。画面1の下に一言出す（§3）。

**読み込みの失敗を無言にしない**

- HTML には最初から「ひらいています…」を書いておき、JS が動き出したら消す。
- JS が読めない・途中で止まったときは、画面に「うまく ひらけませんでした。おうちの ひとに いってね」を出す。

**フォント**

- Zen Maru Gothic（SIL Open Font License）を**画面で使う字だけにサブセット化**した woff2 を `site/fonts/` に置き、ライセンス文も同じ場所に置く（§10-4）。
- 読めなかったときは iPad 内蔵のヒラギノ丸ゴシックで表示する（表示も判定もそのまま動く）。

**動く環境**（iPad Air 2 ＝ iPadOS 15 の Safari）

- Safari 15.0 で動く書き方だけを使う。**使わないもの**: CSS の入れ子（nesting）・コンテナクエリ・`color-mix()`・`:has()`・`dvh`／`svh` の単位・`<dialog>`・JS のトップレベル `await`。
- 古い端末（メモリ 2GB）なので、なぞりの判定は「できた！」を押したときに1回だけ計算する（描いている最中は計算しない・草案のまま）。

**画面の規約**（CLAUDE.md §4 をこの画面に当てたもの）

- インライン `style=` を書かない。**行の色は `data-row="1"`〜`"10"` の属性で CSS 側に10通り書く**（草案は JS で `style` に書いていた）。
- 子ども向けの文字は 20px 以上・押す的は 56px 以上を目安（最低 44px）。
- 行の濃色は、淡色の地との比・白い字との比がどちらも **3:1 以上**。
- 動きは 0.3秒以内・`prefers-reduced-motion` のときは止める。
- 長押しで出る拡大鏡・メニュー、ダブルタップ拡大が出ないようにする（子どもが迷子にならない）。
- 外部リンク・広告・入力欄は置かない。
- ホーム画面に追加したとき全画面で開く（URL バーを出さない）。

**ファイルの置き場**

```
site/
  index.html        … 骨組みだけ（画面1・画面2〜4 の枠）
  css/style.css     … 色・配置・文字
  js/data.js        … 46字と単語（草案の ROWS・NOTE）
  js/icons.js       … 絵 90点（草案の I・viewBox 0 0 64 64）
  js/app.js         … 表・もじページ・読み上げ・なぞり・記録
  fonts/            … サブセットした woff2 とライセンス文
tests/              … データの機械チェック（下）
```

- データの機械チェック: 46字そろっている・キーの重複なし・単語が参照する絵が全部ある・使われない絵が無い。

## 9. やらないこと（初版）

- 濁音・半濁音・拗音・カタカナ・書き順
- 子ども別の記録・端末をまたいだ同期・成績や時間の記録（子ども別は初期段階のあとで考える）
- はなまるを消す画面（消したいときは Safari の設定から Web サイトのデータを消す）
- サーバ側の処理・DB・ログイン
- 効果音ファイル・BGM・自動で鳴る音
- ダークモード
- 業務アプリ（myprojectP）からの配信（草案 §7 の案は採らない）
- 単語や絵の入れ替え（草案のまま出し、実機で子どもが分かりにくかった語だけ後で直す）

## 10. 決めたこと・未決

1. **はなまるを子ども別にするか** → **分けない**（2026-09-14 決定）。初期段階は簡易に、1台に1つ（共有）で作る。あとで分けるときは、最初に「だれ？」を**名前ではなく絵（例: くま／うさぎ）で選ぶ**画面を足す（名前をリポジトリにも画面にも入れずに済む）。
2. **iPad の機種** → **iPad Air 2**（2026-09-14 決定）。§1・§8 に反映した。
3. **NAS の種類・置く場所・開く URL** → **未決・別システムに問い合わせ中**（ユーザーが連絡する）。同じ NAS を**ほかの環境に干渉しない範囲で間借り**する前提。答えが来たら CLAUDE.md §2 の「動かし方」「確認の仕方」と、この節を埋める。問い合わせた内容は下の「NAS への質問」。
4. **フォントの入手** → **取ってきてよい**（2026-09-14 決定）。Zen Maru Gothic を配布元（Google Fonts の GitHub）から取ってきて、手元で使う字だけにサブセット化する（`fonttools` を使う）。

**NAS への質問**（2026-09-14 送付用に用意）

- 置くもの: 静的ファイルだけ（HTML・CSS・JS・woff2、合計 1MB 未満）。サーバで動くプログラム・DB・ページからの書き込みは無い。
- 問1 NAS の機種と OS の版は何か。
- 問2 静的ファイルを配信する仕組み（Web Station・nginx・Docker など）はもうあるか。**今ある設定・フォルダ・ポートに手を入れずに**子ども用ページを1つ足すなら、どの方法がよいか。
- 問3 置き場所にするフォルダのパスはどこか（ほかのシステムのフォルダ・共有フォルダとは分ける）。
- 問4 家の Wi-Fi にいる iPad から開くアドレスは何か（ホスト名か IP・ポート・パス）。Tailscale なしで届くか。http のままでよいか。
- 問5 更新するとき、ファイルをどうやって置くか（SMB でコピー・rsync など）。誰が置くか（ユーザーが手で置くのか、こちらから置いてよい範囲があるのか）。
- 問6 そのフォルダは家の外から見えないか（外部公開していないか）。認証をかけるか。
- 問7 `.woff2` `.js` `.css` `.svg` が正しい Content-Type で返るか。キャッシュが強くかかって更新が iPad に反映されにくい、ということは無いか。
- 問8 使ってはいけないポート・パス・名前、触ってはいけない設定は何か。
